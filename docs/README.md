# 문맥 유형 분류 체크 : AI Agent에게 일 제대로 시키기

문맥 유형 분류 체크를 해주는 '영어 강사의 원어민 비서'를 설계하고, 모델 비교와 검증 과정을 기록한 저장소입니다.

- 비교한 모델: ChatGPT 6, Gemini 자동 모드, Claude Sonnet 5.5 (모두 무료 요금제)
- 대화에 사용한 모델: Claude Sonnet 5.5
